# 桌面人工验收

把此目录作为单独的 Obsidian 库打开，按项目 `CUSTOMIZATION.md` 安装三个插件文件。此库只包含测试文字，可自由修改；不要对正式知识库执行删除测试。

1. 正常复习并显示答案：确认 Again、1/2/3/5/7/10/14/30/60/90 天全部可见且换行可用。
2. 拖动顶部把窗口移到各边缘：答案与进度保持，按钮仍在可见范围。
3. 点击“打开原文”：确认进入当前卡片所在行并可编辑。输入空格、J、S、数字 0，确认文字正常输入且不触发复习动作。
4. 保存“原文同步测试”的问题或答案：浮窗自动更新，显示答案的状态保持。
5. 选择 3 天：确认仅当前卡的 `<!--SR:...-->` 到期日是今天之后第 3 个自然日。重启 Obsidian 后日期仍保留。
6. 在第二张重复问题中编辑答案：确认更新的是正在复习的那张。整块增删完全相同的卡片时，允许提示无法确认身份并停止评分。
7. 在原文删除当前卡或删掉分隔符：浮窗应提示失效，Again 与日期按钮不可提交；点击跳过继续。
8. 在设置里将手动天数改为 `1, 4, 12`：重新打开卡片后按新配置显示，再恢复默认。
9. 把调度算法切到 FSRS，用新卡点击 Again：显示的等待时长和上游相同；选择 N 天后保存天级到期日。
10. 关闭浮窗或停用插件后，确认原文编辑不受影响。
11. 单独复习 `HighlightReview.md`：应有一张带高亮问答、一张独立挖空、一张普通问答，共三张卡；带高亮问答的题干有两个色块，答案追加两个色块，不显示双等号，也不增加挖空卡。
12. 在高亮问答的原文增删高亮、保存并评分：答案状态保持，色块更新，原文保留双等号，独立挖空的计划不变。

本清单可用于后续版本复测。本次已执行的步骤、结果与覆盖边界见项目根目录 `VALIDATION.md`。
